# Editable variables

The web editor exposes the most frequently changed values directly:

- name and role,
- positioning subtitle,
- email,
- LinkedIn label and URL,
- GitHub label and URL,
- location,
- summary,
- availability / CTA,
- repository status,
- color theme.

All other arrays and sections can be edited in `data.js` or by editing/exporting `cybercore-career-data.example.json` and importing it through the web toolbar.
