# CyberCore Career Kit

## Deliverables

- `JAN_KOCI_CYBERCORE_CV_CLICKABLE.pdf` - two-page, selectable text, live hyperlinks, dark/light enterprise theme.
- `JAN_KOCI_CYBERCORE_CV_INVERTED_CLICKABLE.pdf` - inverted light/dark theme.
- `index.html` - editable web version. Open locally in a browser.
- `CYBERCORE_CAREER_KIT_WEB.zip` - portable web package.
- `preview/` - 4K-class PNG previews rendered at 300 DPI.

## Web editor

Open `index.html`. The toolbar allows you to:

- edit core profile and link variables,
- switch the theme,
- export/import configuration as JSON,
- print or save a new PDF.

Changes are stored in browser `localStorage`.
