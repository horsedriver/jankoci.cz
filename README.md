# Jan Kočí — Systems Architect

Source for the public portfolio at [jankoci.cz](https://jankoci.cz).

## Site

The site is a static GitHub Pages deployment built from:

- `index.html` — document shell
- `styles.css` — responsive and print styling
- `data.js` — portfolio content
- `app.js` — presentation rendering
- `assets/` — portrait, CyberCore logo and QR code

Public visitors receive a presentation-only website. There are no browser-side editing, import, export, reset or theme-management controls.

Content changes are made intentionally in the repository and published from the `main` branch.
